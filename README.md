# Banking Transaction Analysis Dashboard | Power BI

## Project Overview

The **Banking Transaction Analysis Dashboard** is an interactive business intelligence project developed using Microsoft Power BI. The objective is to analyze banking transaction data, monitor transaction performance, understand customer activity, and identify potential fraud patterns.

The dashboard transforms raw banking data into meaningful visual insights through interactive charts, KPIs, and filters, helping users explore transaction trends and operational performance.

## Project Objectives

- Analyze overall banking transaction performance.
- Monitor transaction amounts and monthly trends.
- Compare debit and credit transactions.
- Understand transaction distribution across payment channels and types.
- Analyze customer account types and KYC status.
- Monitor failed, successful, pending, and reversed transactions.
- Examine fraudulent transactions across different channels.
- Explore state-wise transaction value distribution.

## Interactive Filters

The dashboard includes interactive slicers to explore the data based on:

- Transaction Direction
- State
- Payment Channel
- Transaction Status
- Transaction Date

These filters allow users to dynamically analyze different segments of the banking data.
